RSS-Feed-Checker und Telegram-Notifier

Dieses Skript überprüft periodisch einen RSS-Feed auf neue Einträge und sendet Updates an einen angegebenen Telegram-Chat. Es ist als Cron-Job konzipiert und nutzt asynchrone Operationen für die effiziente Verarbeitung von Netzwerkanfragen. Die Anwendung läuft in einem Docker-Container auf einem Hetzner-Cloud-Server und wird über eine CI/CD-Pipeline auf GitHub aktualisiert und neu bereitgestellt
